# Famous Paintings

A gallery of famous paintings. Click a painting to open it and read who made it, when and where.

It is a plain static site, so there is nothing to install or build. Open `index.html` in a browser to view it, or host the folder on GitHub Pages.

- `paintings.js` holds the list of paintings. Add or edit entries here.
- `app.js` builds the gallery and runs the pop-up viewer.
- `styles.css` holds the design and animations.

Images are public domain reproductions loaded from [Wikimedia Commons](https://commons.wikimedia.org/).
